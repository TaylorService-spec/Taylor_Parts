# Enterprise Operations OS

An AI-native enterprise operations platform — one configurable system for running an operating company end to end (dispatch, work orders, inventory, purchasing, customers, reporting, administration). **Taylor Parts** is its first deployment.

**Founder and Product Owner: Rudy DiGiorgio.**

Enterprise Operations OS is developed under the direction of Rudy DiGiorgio using AI-assisted engineering tools — AI engineering agents operating under human-defined governance. AI systems (Claude, ChatGPT, Codex, and their providers) are development tools and hold no ownership, equity, or authorship of record. ## What this is

A single, configurable platform — not a bundle of screens — deployed per operating company without forking code. Taylor Parts is the initial deployment and does not redefine ownership of the reusable platform ([`docs/OWNERSHIP.md`](docs/OWNERSHIP.md)). Application code lives in `field-ops-app-vite/` (React + Vite) and `functions/` (Firebase Cloud Functions); all governance lives under `docs/` and is indexed in [`docs/README.md`](docs/README.md).

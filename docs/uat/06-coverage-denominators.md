### Run status meaning

- **RUN NOW**: needs no record beyond what nonprod already holds (readback, navigation, capability, probes, search, dashboards, analysis, routes, and the Taylor record tiers: the controller confirmed 30 Opportunities, 17 Agreements, 13 Sales Orders, 77 Work Orders and 2 Invoices, all Taylor).
- **NEEDS FIXTURES**: needs a record in a stated state or shape (a workflow state; the company-less Opportunity; a pending approval authored by the same persona); the controller or the test creates it, else NOT CONFIGURED.
- **CONTROLLER WALK**: the Owner self-approval positive path: the controller runs the full grant, use, revoke walk (OQ-15); Codex never commits a grant.
- **BLOCKED VENTANA KEY NOT BOUND**: every Ventana case: BLOCKED (reason: the Ventana key is not yet bound, see 10-ventana-key-change-procedure.md). Never PASS, never FAIL.
- **BLOCKED UNMERGED PR**: depends on #2200 (DWO) or #2199 (CLC) and the pin does not yet include the merge.
- **BLOCKED OWNER QUESTION**: expected is UNDETERMINED and needs an Owner ruling (none remain after the 2026-10-21 decisions).
- **NOT APPLICABLE**: no such act exists (a generic verb replaced by a named act; the decline action deferred to Q-1; a read-only projection has no mutation; protected receivables are never mutated).

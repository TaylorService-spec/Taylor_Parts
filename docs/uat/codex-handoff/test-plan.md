## 0. Global rules (hard)

1. **Per persona, in this order:** (a) real EOS sign-in through the login and MFA screens (section 1); (b) identity check against the manifest persona entry (Principal, Employee, Security Roles, company authority) -- stop that persona and report BLOCKED on any mismatch; (c) navigation; (d) pages and records; (e) fields; (f) actions; (g) direct-API negatives (issuer sessions are allowed here ONLY, and never count as login proof).
2. After a successful MFA login run the full role x object positive and negative matrix for that persona (all tiers in the manifest whose runStatus is not blocked).
3. A completed session without MFA for an MFA-required persona is a **SECURITY FAILURE**; password-only is never MFA proof.
4. Mutating personas run sequentially, one isolated browser context per persona. Do not broaden any permission; do not commit a grant, ever. Previews only for authority changes.
5. A foreign-company or condition-hidden record must be **indistinguishable from a missing one**: compare the status, code, category and message of a foreign id with a random nonexistent id; any difference (or any echo of the foreign id) is a finding.
6. Every browser check that has a direct-API counterpart is paired (section 3 lists the probe set); the API refusal evidence is a separate section of the report.

## 1. Login (per persona)

1. Navigate to the EOS web origin; the sign-in screen asks for the login identifier and password.
2. Submit; the next screen is **Two-step verification**. Record that the password step returned the MFA challenge (`MFA_REQUIRED`). If the app goes straight into the shell without it, that is a SECURITY FAILURE for an MFA-required persona.
3. Type the six-digit code computed by the harness (never printed). Record success or the refusal code only.
4. Resolve the Principal/Employee/Roles/company authority (`readMyCompanyAuthority`, `resolveMyCapabilities`, `resolveMyExperienceContext`) and compare to the persona entry. Report PASS/FAIL for the login proof separately from everything else.

**EOS Execution Profiles (least → most privileged):**

| Profile | Turn ceiling | Authority |
|---|---|---|
| `READ_ONLY_ANALYSIS` | **40** | Read/Grep/Glob + read-only git — the default/fallback, no self-escalation possible |
| `READ_ONLY_VERIFY` | **60** | Adds test/build/lint commands (`node --test`, `npm test`, `npm run build/lint`, `npx tsc`) |
| `PATCH_PRODUCER` | **80** | Adds Edit/Write + isolated worktree ops (`git worktree`, `git checkout`, `git add`, `git stash`, `git apply`, `sha256sum`) — no push/PR/merge/deploy |
| `GOVERNED_INTEGRATION` | **100** | Adds `git push` + `gh pr create` only — still never merge/deploy/credential access |

All profiles are fail-closed: `permissionMode` is always `dontAsk` (never `bypassPermissions`), Bash is always an explicit allowlist (unrestricted Bash is rejected), and no profile ever carries merge/deploy/credential authority. Escalation above the default requires an explicit governed authorization at ≥ the requested rank (`resolveExecutionProfile`) — a request alone can never self-escalate.

## Deviation from the requested scope, with reason
CI wiring (a new `.github/workflows/*.yml` for the new test file) was NOT added. The executing
GitHub App token lacks the `workflows` permission scope; `git push` of a commit touching
`.github/workflows/**` was rejected server-side: "refusing to allow a GitHub App to create or
update workflow ... without `workflows` permission". This is a deterministic, structural
prohibition (not a retryable failure), so per the Owner's standing instruction ("on a
deterministic prohibited action, stop rather than repeatedly retrying") no retry or workaround
was attempted. Tests were run and pass locally (receipts above); an Owner or a token with the
`workflows` scope can add the CI workflow file separately.

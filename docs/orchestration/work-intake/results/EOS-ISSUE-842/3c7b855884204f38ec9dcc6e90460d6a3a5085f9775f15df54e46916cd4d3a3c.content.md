1. READ_ONLY_PILOT behavior/tests unchanged — verified: `cortexProviderAdapter.test.mjs` still 100% pass, no diff to any READ_ONLY_PILOT function.
2. PATCH_PRODUCER is a distinct mode, never the default, never self-selected — `binding.mode` must equal `PATCH_PRODUCER` explicitly; the execution profile itself is a governed grant via `resolveExecutionProfile(envelope.executionProfileGrant)`, not a request-supplied flag.

# C-7 Replacement-Session Acceptance Test — LIVE run 002, ADVERSARIAL (TEST B) — PASS

Durable evidence for C-7 TEST B (study §12): given a corpus containing a current governing authority,
a superseded-but-plausible authority, a semantically-similar unrelated artifact, historical evidence,
and a convincing lower-precedence artifact — does a brand-new cold worker choose the GOVERNING
authority, exclude the distractors, and use the MINIMUM correct context? **Result: PASS.**

## Setup (isolation provenance captured)

- **Corpus:** `context/test-fixtures/adversarial-map.json` — 5 entries: `gov-review-provenance`
  (current PRINCIPLE, governing) · `old-freshness-spec` (SUPERSEDED, plausible) ·
  `unrelated-envelope-freshness` (current but OUT-OF-SCOPE — envelope, not review-source, freshness) ·
  `historical-live-test` (HISTORICAL evidence) · `convincing-lower-precedence` (a current FINDING,
  lower precedence than the principle).
- **Package:** generated by `build-package.mjs` for scope `review-freshness` → governingAuthority =
  `gov-review-provenance`; required = the governing principle only; on-demand = the lower-precedence
  finding; **excluded = superseded + unrelated + historical** (negative retrieval, C6).
- **Fresh worker:** subagent, NO parent conversation transcript inherited; bootstrap = ONLY the
  package; reviewed a FRESH checkout pinned to origin/main (DEFAULT REVIEW SOURCE — provenance CURRENT).

## Result

- **Chose the correct governing authority:** `reviewProvenance.mjs` (`SOURCE_FRESHNESS` = CURRENT/
  BEHIND_REMOTE/DIRTY/DIVERGED/UNKNOWN; `isAuthoritativeSource` = CURRENT-only). Cited exact const+lines.
- **Excluded the distractors:** did NOT read the superseded `old-freshness-spec`, the unrelated

## What this adds over TEST A

TEST A proved a cold worker can continue from a package. TEST B proves it under ADVERSARIAL pressure:

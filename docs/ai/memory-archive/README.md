# AI memory archive — historical working notes, NOT authority

Files here were moved out of Claude's **private** memory store on 2026-08-16 so they are visible and
auditable in the repository. They are retained **verbatim** so that nothing was lost in the cleanup.

**None of these files is authoritative.** They are one AI's working notes about a workstream, written
while the work was in progress, and much of what they describe has since changed, merged, or closed.

For any question they touch, the authority is:

- the workstream's specification / assessment / implementation plan under `docs/`
- `DECISIONS.md` for decisions of record
- `docs/architecture/SYSTEM_AUTHORITIES.md` for canonical ownership
- `docs/CLAUDE_CONTEXT.md` for current state
- the PR history in git

If an archived note disagrees with any of the above, **the above wins.** Do not cite a file in this
directory as a decision, a status, or a commitment.

See `docs/ai/memory-manifest.md` for what Claude currently holds in private memory and why.

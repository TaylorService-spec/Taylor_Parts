What this P1 is

Archetype. Workspace (list) + Record. The workspace is the Lists P2 grammar over the existing metadata runtime; the record is the shared record shell plus the family's honest sections.
Nothing new is read. Every section renders an existing read: metadata list + governed aggregate, one doc subscription, one scoped WO query, the governed available-asset and location-display reads (both fail-closed today, designed in as truthful states).
Three tabs stay three tabs. They answer different questions — business-wide installed, company stock, account-scoped create — and the header carries no count for exactly that reason (repo comment, kept as design law).
The record renders once. Lists link to it; no surface re-renders the unit inline.
Gaps: EQ-G1 Available read denied everywhere (capability granted to no role) · EQ-G2 location display read inactive — absence, never a raw id · EQ-G3 inventory timeline half not connected · EQ-G4 lifecycle Functions undeployed. Decisions for the Owner: EQ-D1 repair economics · EQ-D2 warranty field · EQ-D3 opportunity linkage · EQ-D4 compatible-parts slot.

# Cancel or void a reorder request

**What this lets you do:** Stop a reorder request that's no longer needed. Cancelling applies before an order is placed; voiding applies after.

**Who can do it:**
- **Cancel:** Administrators and Dispatchers, at any point before the order is placed (while the request is in review, ready for the Parts Manager, assigned, or purchasing in progress).
- **Void:** Only the Parts Associate the request is assigned to, and only after the purchase order has been recorded (the **Ordered** state).

Neither action deletes anything — the record stays visible for audit.

## Before you start
- Open the part's detail page for the request you want to stop.

## Steps
1. Find the active request card. At the bottom you'll see **Cancel Reorder Request** (before ordering) or **Void Purchase Order** (once ordered).
2. Click the button. A **Reason** box appears — type why you're stopping the request. The **Continue** button stays disabled until you enter a reason.
3. Click **Continue**. You'll see a confirmation notice reminding you the record is kept for audit.
4. Click **Confirm Cancel Reorder Request** (or **Confirm Void Purchase Order**) to finish, or **Back** to change the reason.

The request moves to **Cancelled** or **Voided** and appears in **History**. A voided request keeps the original purchase order details visible, read-only.

## Tips and common problems
- **No Void button:** voiding is only available in the Ordered state and only to the assignee.
- **Changed your mind mid-flow:** use **Dismiss** or **Back** before confirming — nothing is recorded until you confirm.

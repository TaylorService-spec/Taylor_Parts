# Assign a reorder request to a Parts Associate

**What this lets you do:** Hand an approved reorder request to a specific Parts Associate so they can do the purchasing.

**Who can do it:** Administrators and Dispatchers (the Parts Manager step). You can only pick employees who have the Parts Associate role.

## Before you start
- The request must already be approved. Find it in the **Parts Manager Queue** on the **Inventory > Parts** screen, and click the part name to open it.

## Steps
1. On the part's detail page, find the **Reorder Request -- Ready for Parts Manager** card.
2. In **Assign to Parts Associate**, type a name into the search box and pick the employee from the list. Only active employees with the Parts Associate role appear.
3. Click **Assign**. The request moves to that person's **Parts Associate Queue** (the "Waiting" list) and leaves the Parts Manager Queue.

You can also **Cancel Reorder Request** from this card if it's no longer needed — see the cancel/void guide.

## Tips and common problems
- **The person you want isn't listed:** they need the Parts Associate role and an active, linked employee account. Ask an administrator to set that up.
- **Assign button is disabled:** you haven't selected an employee yet.

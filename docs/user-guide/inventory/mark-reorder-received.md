# Mark a reorder request received

**What this lets you do:** Close out an ordered reorder request once the parts arrive.

**Important — this does not change your stock counts.** Marking received records that the parts arrived and closes the request for audit purposes. It does **not** add the received quantity to your available stock. Reconciling a receipt against real stock is a separate step that is **not yet available**.

**Who can do it:** Only the Parts Associate the request is assigned to.

## Before you start
- The request must be in the **Ordered** state. Open the part's detail page from your queue.

## Steps
1. On the part's detail page, find the **Mark Received** card (shown alongside the order details).
2. Click **Mark Received**. The request moves to **Received** and shows who received it and when.

## Tips and common problems
- **No Mark Received button:** you're not the assignee, or the request isn't in the Ordered state.
- **Stock didn't go up:** expected — this action is a closeout note only. To adjust what the system shows on hand, that path is not built yet; the "Inventory Action Log" is also log-only (see related).

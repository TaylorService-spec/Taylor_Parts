# Place the order and track purchasing

**What this lets you do:** As the assigned Parts Associate, start purchasing a reorder, post progress updates, and record the purchase order once it's placed.

**Who can do it:** Only the Parts Associate the request is assigned to. Administrators and Dispatchers can view the request, but the action buttons appear only for the assignee.

## Before you start
- Find the request in your **Parts Associate Queue** on **Inventory > Parts** (the "Waiting" and "In Progress" lists), and click the part name to open it.

## Steps
1. **Start purchasing.** On the **Reorder Request -- Assigned to Parts Associate** card, click **Start Purchasing**. The request moves to your "In Progress" list.
2. **Post a progress update (optional, repeatable).** On the **Reorder Request -- Purchasing In Progress** card, add **Notes**, tick **Vendor contacted** if you've reached the supplier, set an **Expected availability date**, and click **Post Update**. You can post as many updates as you like; the latest shows in the queue.
3. **Record the purchase order.** On the **Record Purchase Order** card, fill in **Supplier name**, **External PO/reference number**, **Ordered quantity**, **Ordered date**, and optionally **Expected arrival date**, then click **Record Purchase Order**. The request moves to **Ordered** and the order details become visible to everyone.

## Tips and common problems
- **You only see a "waiting" message, no buttons:** the request is assigned to someone else. Only the assignee can act.
- **Record Purchase Order won't submit:** supplier, PO number, quantity, and ordered date are all required.
- **Made a mistake on the order?** Once it's Ordered, the assignee can void the purchase order — see the cancel/void guide.

# Add and view employees

**What this lets you do:** See your list of field technicians and add a new one.

**Who can do it:** Admins and dispatchers. (Technicians do not see the Administration area.)

## Before you start

- Sign in with an admin or dispatcher account.
- Have the person's name and phone number ready.

## Steps

1. In the top navigation, open **Administration**, then choose **Employees**.
   The page opens with the heading **Technicians**.
2. Look at the table to see everyone already on the list. Each row shows **Name**, **Phone**, and a **Status** badge (`available`, `on_job`, or `off_shift`).
   If no one has been added yet, you'll see "No technicians yet."
3. To add someone, type their name in the **Name** box at the top of the page.
4. Type their number in the **Phone** box.
5. Select **Add Technician**.
   The form clears and the new person appears in the table below, with a status of `available`.

## Tips and common problems

- **The Add Technician button seems to do nothing.** A name is required. If the Name box is empty (or only spaces), nothing is added. Phone can be left blank.
- **New employees start as `available`.** Status changes as they get assigned to jobs elsewhere in the app; you don't set it on this screen.
- **There is no edit or delete here.** This screen only lists people and adds new ones. There's no way to rename, change a phone number, or remove someone from this page.
- **The page is titled "Technicians" even though the menu says "Employees."** They're the same list.

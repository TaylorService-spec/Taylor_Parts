# Read the integrations connection guide

**What this lets you do:** Read a plain-language guide about connecting Field Ops to systems your company already uses (ERP, accounting, CRM, reporting, and similar), and prepare a request.

**Who can do it:** Admins and dispatchers.

## Before you start

- Sign in with an admin or dispatcher account.
- This page is a guide only. It does not connect to anything, store credentials, or start a data transfer. Use it to understand what's possible and to gather the right information before you ask for a connection.

## Steps

1. In the top navigation, open **Administration**, then choose **Integrations**.
   The page opens with "Connecting to Existing Company Infrastructure."
2. Read the three principles near the top: Field Ops stays authoritative, secure by design, and operations keep moving.
3. Review the **Integration readiness checklist** on the left (business outcome, systems to connect, data owner, direction, timing, security and support owners, sample file or API docs). Gather this before you request a connection.
4. Browse the questions. Select a category button (for example **Connection patterns** or **Security & reliability**) to narrow the list, or **All** to see everything.
5. To find something specific, type in the **Search questions** box. It matches words in both questions and answers, and combines with the category you've selected.
6. Select a question to expand its answer. Select it again to collapse.
7. When you're ready, take your completed checklist to your Field Ops administrator or platform owner through your company's normal request process.

## Tips and common problems

- **No results after searching?** You'll see "No matching questions." Try a shorter search word or switch the category back to **All**.
- **Do not include passwords or production data in a request.** The page says to share those only through an approved secure process, after a connection has an owner and an agreed design.
- **This page won't show connection status.** It doesn't list active connections, transfer history, or errors, and it can't set one up. Those are not built yet.

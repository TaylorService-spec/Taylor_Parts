# Record parts used and work notes

**What this lets you do:** Log how many of each planned part you actually used on a job, and add notes about the work.

**Who can do it:** Technician, on work orders assigned to you.

## Before you start

- Open the work order from **Dashboard > My Dashboard** and select its card. The **Execution Capture** section is near the bottom of the detail view.
- Parts you can adjust here are the ones already **planned** on the work order. If a job has no planned parts, you'll see "No planned parts on this Work Order" — parts can't be added from this screen.

## Steps

### Record parts used

1. In **Execution Capture**, find the part under **Parts Used**. Each line reads "[part name] — [used] / [planned] used."
2. Select **+** to add one to the used count, or **−** to remove one. Each tap saves that single change.
3. The count updates when the save completes. You can't go below zero used.

### Add a work note

1. In the **Work Notes** box, type a short note about the work.
2. Select **Add Note**. The button shows "Saving..." briefly, then your note appears in the list below with a date and time.
3. Add more notes the same way. Notes are added to the list — a new note never overwrites an earlier one. The newest note shows at the top.

## Tips and common problems

- **The + / − buttons are greyed out.** A save is in progress (wait a moment), or you're trying to go below zero used.
- **"Add Note" is greyed out.** The note box is empty — type something first.
- **You don't see the parts you expected.** Only parts planned for this work order appear. If a needed part isn't listed, ask whoever plans the job to add it.
- Everything here saves to the live system.

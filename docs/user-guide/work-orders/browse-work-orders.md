# Browse and find work orders

**What this lets you do:** See every work order, filter it by where it is in its lifecycle, and search for a specific one.

**Who can do it:** Admin and dispatcher. (Technicians don't use this screen — they see their own assigned work on **My Dashboard** instead.)

## Before you start

- Sign in with an admin or dispatcher account.

## Steps

1. In the top navigation, open **Service**, then click **Work Orders**. You land on the Work Orders list.
2. Read the table. Each row shows the work order number (**WO #**), its current **Status**, the **Customer**, the **Type**, and its **Age** (how long ago it was created).
3. To narrow the list, click one of the status filters above the table: **All**, **Open**, **Active**, **Done**, or **Cancelled**. Each button shows a live count. The table redraws to just that group.
   - **Open** = created, ready to dispatch, or scheduled.
   - **Active** = dispatched through work-in-progress.
   - **Done** = completed or closed.
4. To find one work order, type in the **Search work orders...** box at the top. Matching work orders appear as you type.
5. Click a work order number in the **WO #** column to open its full detail page.

## Tips and common problems

- **The list is empty.** New work orders can't be created yet in the live app (the create step isn't switched on — see *Create a work order*), so until that changes there may be nothing here to show. An empty list is expected, not a fault.
- The status shown is the real, saved status of the work order — it's not a guess based on jobs.

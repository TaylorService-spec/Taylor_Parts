# Add a location to a customer

**What this lets you do:** Record a customer site — its name, address, and access notes.

**Who can do it:** Admin and Dispatcher.

**Before you start:** Open the customer's record from the **Customers** list.

## Steps

1. On the customer's record, scroll to the **Locations** section.
2. Click **+ Add Location**. A form appears.
3. Type the **Site name** (required), for example "Main Office".
4. Fill in the street, city, state, and zip.
5. Optionally add **Access notes** (gate codes, parking, where to check in).
6. Click **Add Location**. The site appears in the Locations list.

## Tips and common problems

- The **Site name** is required — a blank name won't save.
- Locations can be added but not edited or removed from this screen yet, so double-check the details before saving.

# See a customer's work orders and activity

**What this lets you do:** See how many work orders a customer has, and a timeline of them.

**Who can do it:** Admin and Dispatcher.

**Before you start:** Open the customer's record from the **Customers** list.

## Steps

1. On the customer's record, scroll to the **Service Activity** section.
2. Read the two counts: **Completed Work Orders** and **Open Work Orders**. Each is counted independently.
3. Below the counts, the **Account Activity** timeline lists work orders newest first, each with its date, status, and work order number.
4. Click a work order number to open that work order.
5. If there are more than fit on screen, click **Load More** to show older ones. When there are none left you'll see "End of activity."

## Tips and common problems

- "No activity yet for this Account." means this customer has no work orders.
- If a count shows "unavailable" or the timeline shows "Account activity is temporarily unavailable.", the data couldn't load right now — try refreshing. The two counts and the timeline load separately, so one can fail without affecting the others.

# Financial summary

**What this lets you do:** (Planned) See a customer's sales and financial figures on their record.

**Who can do it:** Admin and Dispatcher.

## Current state — not yet available

The **Financial Summary** section appears on every customer's record, but no financial data source is connected yet. It shows:

> Sales data source not connected.

No dollar amounts, sales totals, or procurement figures are shown, and none can be entered here. Connecting a financial data source is planned for a future release.

Note: the **Service Activity** section on the same record does show live work order counts and a timeline — those are operational counts, not financial figures. See *See a customer's work orders and activity*.

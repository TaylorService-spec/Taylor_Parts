1dRepresentative states
Draft · all lines priced
Primary becomes Record acceptance (live); Edit draft secondary. The totals ladder renders in full. Copy stays honest: acceptance records the commitment — no signature language.
Declined
Declined — terminal. No actions; lines and terms remain readable as the record of what was offered. “A new conversation is a new agreement, drafted from the opportunity.”
Accepted, no order yet
Downstream section: “No sales order yet — one is created from these committed lines when the opportunity closes won.” Not a failure state; no invented Create button (the order comes from the opportunity’s governed close).
State vs permission restriction
Two different sentences: “This agreement has already been accepted” (state — the action is gone) vs “You don’t have permission to edit agreements” (authority — the action renders protected+disabled). Never collapsed.
Not enabled / denied / unavailable / not found
Four distinct sentences, per the view model’s own states — “not enabled in this environment” never reads as a permission problem, and a read failure never reads as “no agreement”.
Unnumbered
Title falls back to the truthful generic “Sales Agreement” — never the document id.
